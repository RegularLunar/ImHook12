# ImHook12
> A minimal internal DirectX 12 overlay hook using MinHook and Dear ImGui

---

### Features

- DX12-only, x64, with no dependency on kiero or other hook libraries
- MinHook-based
- Minimalistic for easy building
- ImGui v1.93.0

---

### Building From Source

**You will need the following:**
- **[Visual Studio](https://visualstudio.microsoft.com/downloads/)**
- **[Windows SDK](https://learn.microsoft.com/en-us/windows/apps/windows-sdk/downloads)**
- **[Premake5](https://premake.github.io/)**

   ```powershell
   git clone https://github.com/RegularLunar/ImHook12.git
   cd ImHook12
   premake5 vs2022
   ```
